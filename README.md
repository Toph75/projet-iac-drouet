# IaC Mastère 4A

Ce dépôt regroupe l'ensemble des travaux pratiques du module Infrastructure as Code (IaC).
Il couvre l'apprentissage et la mise en pratique des outils Git, Terraform et Ansible.
Le projet permet d'historiser la progression et la structure du travail sur l'ensemble du module.

## Observations

Lorsqu'on modifie le fichier `README.md` après un premier commit sans exécuter `git add`, le fichier se trouve dans la **zone de travail** (*Working Directory*). Ses modifications ne sont pas encore indexées (*Not staged for commit*).
